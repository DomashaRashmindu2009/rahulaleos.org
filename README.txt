LEO CLUB OF RAHULA COLLEGE — EXUBERANCE '26
Roman Imperium website starter.

HOW TO RUN
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Put your own images in assets/ and replace the image/content placeholders.

IMPORTANT
- The hero currently references assets/hero.jpg. Add your preferred hero image with that filename.
- Replace member names, contact details, dates and project information with official information.
- The contact form is front-end only; connect it to a form/backend service before production.
